# 積木減脂：飲食 × 體重

開始使用：https://z88487561.github.io/diet-weight-tracker/

## 分頁
| 分頁 | 內容 |
|---|---|
| 今日飲食 | 四餐積木記錄、7 天日期列、當日體重、複製昨日、範本、手動輸入外食 |
| 體重 | 目標與計畫（減重／維持）、每日判定、教練回饋、SVG 圖表、連續達成與徽章、紀錄列表、體重 CSV |
| 趨勢 | 近 7 天／近 30 天／全期的熱量與體重；資料足夠（有效紀錄日夠多）才顯示減脂評估 |
| 食材範本 | 上百項食材庫、搜尋與常用、範本管理 |
| 設定 | 身高／性別／年齡／活動量、BMI／BMR／TDEE、熱量與蛋白質目標、量體重提醒、完整備份 |

## 檔案
```
index.html            主程式（飲食 + 設定 + 整合）
js/weight.js          體重模組
tailwind.css          預先編譯的樣式（Tailwind 3.4.19）
vendor/               Chart.js 4.6.1、Lucide 1.61.0（固定版本、本地載入）
sw.js                 Service Worker（離線快取）
manifest.webmanifest  PWA 設定
icons/                App 圖示
```


## 備份
- **完整備份（JSON / CSV）**：飲食 + 體重 + 食材庫 + 範本 + 設定，在「設定」分頁。超過 7 天沒備份會提醒。
  - JSON：「匯出完整JSON」「匯入完整JSON」（覆蓋）。
  - CSV：「分享完整CSV」「下載完整CSV」「匯入完整CSV(覆蓋)」「合併匯入完整CSV」。同一個檔案分段（`#meta`、`#profile`、`#weight_settings`、`#weight`、`#foods`、`#templates`、`#meals`），可用試算表開啟。
  - 合併只補缺少的資料，不刪除也不修改現有內容：飲食以「日期＋餐別」判斷（本機該餐已有內容就保留本機）、體重以「日期＋時間」、食材與範本以 id；個人設定維持目前的。
- **體重 CSV**：只含體重與目標，格式與原本體重紀錄 App 相同，可合併匯入。
- 匯入前都會建立快照，可一鍵還原。

## 新增（v7）
- **開啟時的預設頁面**：設定 → 開啟時的預設頁面（今日飲食／體重／趨勢）。首次引導選「只記體重」會自動設成體重頁。
- **體重顯示到小數點後兩位**（例：71.25 kg），輸入欄 step 0.01，儲存時四捨五入到兩位。
- **左右滑動換頁**：順序同底部選單；從輸入欄、可橫向捲動的區塊、或有視窗開啟時開始的滑動不會換頁；螢幕左右邊緣 20px 留給系統手勢。
- **每餐「完成／編輯」**：未記錄時預設編輯狀態；按「完成」後鎖定，只顯示有記錄的項目；按「編輯」可再改。升級前已有內容的餐點視為已完成。有選食物但沒填份量時不能完成。
- **選完食物自動跳到份量欄**（餐點與範本編輯都適用）。
- **趨勢**：新增近 30 天、全期；減脂評估只在「有效紀錄日」夠多時才顯示（至少記 2 餐且合計 ≥ 700 kcal；7 天需 3 天、30 天與全期需 7 天），熱量曲線也只畫有效紀錄日。
- `sw.js` VERSION 升到 v8；資料版本升到 7。

## 先前版本（v6）
- **首次引導**：先問「記飲食 / 記體重 / 兩個都要」，只問當下用得到的最少欄位；每一步都能跳過。體重一輸入就先記下第一筆。
- **預設值不拿來判定**：身高、目標熱量、蛋白質要「確認過」才會用來判定。沒確認時，熱量卡是中性色、BMI 顯示「先到設定填身高」。舊使用者升級後視為已確認。
- **設定進度卡**：飲食頁與體重頁頂端的「完成設定 n/N」，一次只推下一步，可隱藏。
- **判定偏向趨勢**：以 7 日平均對照目標線；單筆只上色（綠＝達標、黃＝在自然波動內、紅＝明顯偏離）；連續達成改用趨勢判定。
- **預測分三層**：① 狀態（領先／落後幾公斤、約幾天進度）② 可行性（準時需每週減多少、是否超過安全上限、以安全速度最快何時）③ 實測預估（近 4 週與整體速度，給區間；比原定晚 8 週以上就不給日期）。落後時會對照近 14 天攝取給診斷。
- **範本**：點開先看逐項明細與合計；可「取代」或「加到這一餐」；任何單餐範本都能編輯、另存、刪除；套用／清除／複製昨日都有「復原」。
- **最近常吃自動置頂**：依餐別與近期頻率自動排序，不必維護；★ 常用仍然最優先；搜尋支援別名。
- **食材 CSV 友善化**：中文欄位與分類、「每100g / 每1杯」基準、可省略 id、別名欄、匯入前預覽（新增／更新／有問題的列）、可復原；舊格式 CSV 仍可匯入；附範例檔下載。
- **每日目標的參考表**：新手引導的「你的每日目標」會附上「成人每日熱量需求參考表」，並標出符合你性別的那一列；資料不足算不出建議值時，也會改成手動填寫並對照這張表。
- **提醒**：備份提醒（超過 7 天）可直接匯出；未安裝時提醒加入主畫面，附 iOS / Android 教學。

## 外觀與樣式
- **深色模式**：設定 → 外觀，可選「自動（跟隨手機）/ 淺色 / 深色」，選擇會被記住。
- **各餐配色**：早餐琥珀、午餐天藍、晚餐靛藍、消夜紫（左側色條 + 標題列底色）。
- `tailwind.css` 是編譯產物（Tailwind + 自動產生的深色規則）。新增或修改畫面上的顏色 class 後，要重新產生：
  ```
  cd tools
  npm install        # 只需第一次
  ./build.sh         # 需要 Node.js 與 Python 3
  ```
  `tools/gen_dark.py` 會掃描 `index.html` 與 `js/weight.js` 用到的顏色 class，自動產生對應的深色規則。

## 圖示
- 圖示依 `tools/icon_reference.jpg` 的設計重新繪製（背景 #107d75、體重計＋刀叉＋條碼）。想微調顏色或造型，編輯 `tools/make_icons.py` 後執行 `python3 tools/make_icons.py`（需要 Pillow 與 numpy）即可重新輸出 `icons/` 下四個尺寸。
- 已安裝的 App 更新後，圖示可能要等重新開啟一兩次才會換；iPhone 的主畫面圖示要刪掉重新「加入主畫面」才會更新。

## 與舊版的差異
- 身高只有一份（設定分頁），BMI 與 TDEE 共用。
- 可以在尚未設定目標時先記錄體重。
